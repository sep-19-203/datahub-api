# Danh sách vấn đề đặc tả API (`API HDDT - TTHC - TMS.xlsx`)

Trạng thái: **CONFIRMED** (đã có căn cứ duyệt) · **CONFLICT** (đặc tả tự mâu thuẫn) · **MISSING** (thiếu thông tin) ·
**PROPOSED** (phương án đề xuất đang dùng cho POC, cần duyệt) · **BLOCKED** (không thể triển khai đúng nghiệp vụ khi chưa xác nhận).
Nguyên tắc: bảng mô tả field > ví dụ curl/JSON. Căn cứ nghiệp vụ bổ sung: `Hoàn thuế GTGT.xlsx` (SHA-256 `a11ba045…d095`, 11/10/2026) — đặc tả API 31/10 mới hơn được ưu tiên khi mâu thuẫn. Chốt của người dùng ngày 31/10 ghi rõ "người dùng chốt". Vấn đề ảnh hưởng số tiền / trạng thái thuế / quyền truy cập / sổ hoàn ⇒
**không tự giả định**: code chặn bằng cờ cấu hình (mặc định an toàn) và trả lỗi rõ ràng.
